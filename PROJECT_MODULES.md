# Suggested Academic Documentation Modules

## Module 1 — Product Management
Displays mock products with category, price, stock, rating and discount.

## Module 2 — Search & Discovery
Live search across product name, category and badge.

## Module 3 — Smart Filtering
Category filtering and price/rating sorting.

## Module 4 — Cart Management
Add, remove and change quantity using React state + LocalStorage.

## Module 5 — Wishlist
Save products for later using LocalStorage.

## Module 6 — Checkout
Collect customer details and simulate UPI/card/COD selection.

## Module 7 — Order Processing
Django accepts a JSON order and returns a generated order ID.

## Module 8 — Analytics Dashboard
Revenue, order, customer and inventory metrics with visual charts.

## Module 9 — Responsive UI
Desktop, tablet and mobile layouts.

## Module 10 — Future Scope
MySQL, authentication, payment gateway, reviews, recommendations, email, delivery tracking and admin CRUD.
